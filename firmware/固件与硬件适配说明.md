# 固件与硬件适配说明（ESP32-C3 / 4MB Flash）

> 本文件是固件与采购硬件的硬约束清单。任何新增功能都必须在这份约束内，不能因为加功能把 Flash 或 RAM 顶穿。

## 一、实测容量（来自真实编译产物，非估算）

| 项目 | 实测值 | 硬件/分区容量 | 占用率 |
|---|---|---|---|
| 应用固件 bin | 1,115,008 B（1.06 MB） | app0 分区 1,966,080 B | **56.7%**（余 851 KB） |
| 整片烧录镜像 merged.bin | 4,194,304 B | 4 MB Flash | 100%（正好一片，不多不少） |
| DRAM 静态占用 | .data 14,453 B + .bss 25,464 B ≈ 40 KB | C3 可用 DRAM 约 320 KB | 12%，剩余堆约 222 KB |
| IRAM 静态占用 | 64,956 B | 约 384 KB | 17% |
| Flash 代码段 | .text 856,850 B + .rodata 138,120 B | — | — |

## 二、分区表（当前使用，OTA 双分区）

| 分区 | 偏移 | 大小 |
|---|---|---|
| nvs | 36,864 | 20,480 |
| otadata | 57,344 | 8,192 |
| app0 | 65,536 | 1,966,080（1.875 MB） |
| app1 | 2,031,616 | 1,966,080（1.875 MB） |
| spiffs | 3,997,696 | 131,072 |
| coredump | 4,128,768 | 65,536 |

合计 4,157,440 B / 4,194,304 B = **99.1%**。

**这张表要求 Flash 必须为 4 MB。2 MB 模组装不下，会启动失败或 OTA 必失败。**

Arduino IDE 对应选项：`Minimal SPIFFS (1.9MB APP with OTA)` 或等效的 4 MB 自定义分区表。
**不要用** `Default 4MB with spiffs`——它只有一个 APP 分区，OTA 必然失败。

## 三、引脚分配与硬件约束

| 功能 | 引脚 | 约束与风险 |
|---|---|---|
| 雷达 LD2410C（Serial1） | RX=GPIO4 / TX=GPIO5，256000 8N1 | 合规，无冲突 |
| MQ 燃气（ADC） | GPIO3 | 属 ADC1 通道，合规 |
| 光敏（ADC） | GPIO1 | 合规 |
| 电池分压（ADC） | GPIO0，×2.0 折算 | GPIO0 = ADC1_CH0，**不是 strapping 脚**，可以直接用（原文档此处写错，已按 Espressif 数据手册更正）。注意 ESP32-C3 真正的 strapping 脚是 **GPIO2 / GPIO8 / GPIO9**，改板时不要挪到这三根上 |
| 声敏（数字） | GPIO20 | **GPIO20/21 是 UART0（USB 串口）**：占用后烧录与看日志必须先拔这两根线。量产建议改到 GPIO8/9 之类普通脚 |
| SHT3X（I2C） | SDA=GPIO6 / SCL=GPIO7，地址 0x44 | 合规 |

## 四、内存使用红线（后续加功能必须遵守）

1. **app bin 不超过 1.60 MB**（当前 1.06 MB）。留给 app 分区 1.875 MB 至少 270 KB 余量，避免 OTA 写入时空间不足。
2. **DRAM 静态（.data+.bss）不超过 80 KB**（当前约 40 KB）。剩余要留给 WiFi + MQTT + TLS 握手，实测 TLS 峰值需要 40–60 KB 连续堆。
3. 禁止在全局声明超过 4 KB 的数组；大缓冲用 `static` 局部或分块流式处理（OTA 下载已按块写）。
4. 所有 JSON 解析使用固定容量文档，禁止无上限 `DynamicJsonDocument`。

## 五、编译与验证方法

本机 `arduino-cli` 全量编译不可用（会卡在 Detecting libraries 十几分钟无产物）。可行方法：

```bash
GXX=~/.arduino15/packages/esp32/tools/esp-rv32/2601/bin/riscv32-esp-elf-g++
LIBS=~/.arduino15/packages/esp32/tools/esp32c3-libs/3.3.12
$GXX -fsyntax-only -Wno-deprecated-declarations \
  -iprefix $LIBS/include/ \
  @$LIBS/flags/includes @$LIBS/flags/defines @$LIBS/flags/cpp_flags \
  -I$LIBS/qio_qspi/include -I$LIBS/qio_qspi \
  -I<core>/cores/esp32 -I<core>/variants/esp32c3 \
  @myinc.rsp sketch.cpp
```

要点：
- 必须带 `-iprefix`，否则报 `sdkconfig.h` 找不到；
- 必须把函数原型手工插到**第一个函数定义之前**（等同 Arduino 预处理），否则 `Params` 等自定义类型未声明，产生大量假错；
- 当前源码校验结果：**0 error**。
